# Steam publishing

The path for one game, start to finish. `tools/release` does the mechanical parts, and this skill is the judgment around it.

## Read in this order

1. `games/<slug>/LAUNCH.md`: where this game is on the path.
2. The topic file for the step you are on.

## Topic files

- `runbook.md`: the path for one game, phase by phase, with who does what. Start here for "ship this game".
- `requirements.md`: the platform's rules and timing, each with its source and the date it was checked.
- `store-page.md`: art sizes, copy rules, pricing, and how to fill the page.
- `builds.md`: steamcmd, depots, branches and the cached login.

## What needs a human

Paying fees, accepting agreements, typing bank, tax or identity details, approving store copy, and pressing Release. Carry everything else end to end and report.
